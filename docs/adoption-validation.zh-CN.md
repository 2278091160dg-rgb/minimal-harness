请三名从未使用本项目的开发者，在没有维护者指导的情况下按照对应页面试用。在记录参与者
自己的答案之前，不解释证据过期结果。只能使用可丢弃的 Git 项目，不使用生产仓库。第一阶段
只需要终端，不要求 AI Agent。

三人样本只统计已经具备 Git 和 Python 3.9+ 的参与者。缺少依赖要记为前置门槛流失，再另找
一名参与者；不要把本次 Harness 试用变成操作系统软件安装测试。

## 试用任务

1. 按固定系统页面完成第一次通过验收。
2. 在通过后修改示例源码，不经提示解释报告变化。
3. 恢复、重验、完成，并解释交接文件给出的下一步。
4. 可选：在自己的项目副本中安装 release，并把一条已有测试命令定义为验收。

验收目标：三人都能在维护者不介入的情况下完成第一项流程，并正确解释证据过期报告。
将失败记为需要改进的发现，不归咎为“用户操作错误”。在增加集成或编排功能前，
优先解决重复出现的卡点。

逐字保留系统页要求回传的六项答案：环境、耗时、首个卡点及原始输出、证据过期解释、
项目副本结果和再次使用意愿。维护者观察写在本表，不要写入参与者页面。
