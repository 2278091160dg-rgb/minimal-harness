## Medium launch post

### English

Coding agents are good at producing changes, but “the code was written” is not
the same as “the task is complete.”

Minimal Harness is a repository-local, agent-neutral completion proof layer. It
tracks a deterministic task lifecycle, captures a strict Git baseline, binds
command/browser/manual evidence to the verified Git state, blocks stale or
tampered results, and generates a trustworthy handoff for the next session.

The runtime is Python 3.9+ standard library only. It does not call an AI model,
orchestrate agents, commit code, or pretend to be an OS sandbox.

## Why this is more than CI

CI proves that selected commands passed for a revision. Minimal Harness also
answers:

- Which task was active and which acceptance criteria applied?
- What Git branch, HEAD, index, worktree, and allowed-path baseline was frozen?
- Which log or artifact was actually verified, and is its SHA-256 still valid?
- Did relevant code or Git history change after the result passed?
- Is the completion decision safe to carry into the next agent session?

It complements CI; it does not replace CI.

## Reusable use cases

1. **Agent handoff:** one coding agent stops and another resumes without trusting
   a prose-only summary.
2. **Browser acceptance:** a UI task cannot pass with a text claim alone; it
   needs the named browser tool and a bound screenshot artifact.
3. **Scope control:** a task may edit `src/**` and `tests/**`, while completion
   fails if unrelated repository paths changed.

# Minimal Harness v0.1.1

## Download

- [minimal-harness-v0.1.1.zip](https://github.com/2278091160dg-rgb/minimal-harness/releases/download/v0.1.1/minimal-harness-v0.1.1.zip)

The ZIP expands directly to `.harness/`.

## What it does

- Tracks a deterministic coding-task lifecycle.
- Freezes Git and policy baselines when work starts.
- Binds command, browser, and manual evidence to the verified Git state.
- Fails closed on missing, stale, tampered, or uncertain completion proof.
- Generates a validated cross-session handoff.
- Runs on Python 3.9+ with no third-party runtime dependency.

## Quick start

```bash

python3 -m zipfile -e minimal-harness-v0.1.1.zip .
```

## Security boundary

Minimal Harness is a completion gate, not an operating-system sandbox,
authorization system, cryptographic signature service, or proof that a manual
attestation is truthful. Run untrusted code in a container, VM, or restricted
account.
