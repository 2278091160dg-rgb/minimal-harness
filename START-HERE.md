# Start here: your first Minimal Harness run

[简体中文](START-HERE.zh-CN.md) · [Project README](README.md)

This is the short path for a first-time user. You do not need to understand harnesses
first, and you do not need a GitHub account, a model API, or an AI agent. Stage 1 takes
about 15 minutes. Stage 2 is an optional 20-minute attempt in a disposable copy of your
own project. Both platform paths use the fixed `v0.2.0-beta.2` release.

## Check the safety boundary first

- Use only the demo directory created by the guide or a **disposable copy** of your project.
- Do not use a production project, the only copy of a project, or a directory with secrets.
- The guide does not require administrator access or ask you to delete directories.
- Git and Python 3.9 or newer must already be installed. The platform page checks them;
  stop if either check fails.

## Choose your system

- [macOS: use Terminal and `python3`](docs/first-use-macos.md)
- [Windows 10/11: use PowerShell and `py -3`](docs/first-use-windows.md)

Open only the page for your system. Do not mix the two command sets. If the output differs
from the page, stop, keep the last 20 terminal lines, and tell the person who invited you.
A failure is useful feedback. Do not edit state or evidence files inside `.harness/`.
